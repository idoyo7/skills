# 메모 - redis 이슈

## 증상

오늘 오전에 redis latency 튀는거 발견. p99가 평소 2ms인데 350ms까지 감

## 확인한것

- redis-cli --latency 돌려봄. 결과 비슷하게 튐
- INFO 봤는데 connected_clients 갑자기 800개까지 올라감 (평소 60~80)
- 근데 슬로우로그는 깨끗함... 이상함

일단 클라이언트 수 급증이 원인같긴한데 왜 늘었는지 모르겠다

## 나중에 알게된것 (오후)

배포파이프라인에서 새로 배포된 서비스가 커넥션풀 설정을 안하고 매 요청마다 새 연결
만들고 있었음. maxIdle=0 이었던듯. 확인해보니 pool 라이브러리 버전 올리면서 기본값이
바뀐거였다

- pool 라이브러리 버전: 3.2 -> 4.0
- 4.0에서 maxIdle 기본값이 10에서 0으로 바뀜 (release note에 있긴 했는데 아무도 안읽음)
