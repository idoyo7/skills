# 중첩 리스트와 체크박스

## 3단 중첩 불릿

- 첫 번째 레벨 항목 하나
  - 두 번째 레벨 항목
    - 세 번째 레벨 항목, 여기까지 들어간다
    - 세 번째 레벨 항목 둘째
  - 두 번째 레벨 항목 둘째, 코드도 포함
    ```bash
    echo "리스트 안에 들어있는 코드블록"
    ```
- 첫 번째 레벨 항목 둘, 바로 하위에 번호 목록
  1. 하위 번호 항목 1
  2. 하위 번호 항목 2
     - 번호 항목 아래에 다시 불릿
     - 하나 더

## 번호 목록과 체크박스 혼합

1. 준비 단계를 마친다
2. 다음 항목들을 확인한다
   - [ ] 아직 안 한 일
   - [x] 이미 끝낸 일
   - [ ] 진행 중인 일
      - [ ] 그 하위의 세부 항목
3. 마지막 단계로 넘어간다

## 리스트 안의 들여쓰기 코드블록 (4칸)

- 항목 설명이 길게 이어지다가

    이건 4칸 들여쓰기된 코드 블록이다. 리스트 컨텍스트 안에 있으므로
    이 스킬의 규칙상 별도의 indent_code 블록으로 취급하지 않고
    리스트 항목의 연속으로 처리되어야 한다 (계약서: "리스트 컨텍스트 안이면 제외").

- 다음 항목으로 이어진다

## 빈 줄 뒤 진짜 들여쓰기 코드 블록 (리스트 바깥)

일반 문단이 여기서 끝난다.

    이건 리스트 컨텍스트가 아니라 순수한 문단 사이에 낀 4칸 들여쓰기 코드 블록이다.
    이 경우에는 indent_code 로 마스킹되어야 한다.

이 문단은 코드 블록 다음에 이어지는 평범한 문단이다.
