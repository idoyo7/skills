# 공백/개행 경계 테스트

이 문서는 CRLF 줄바꿈, 끝 개행 없음, 탭 들여쓰기, 연속 빈 줄, 유니코드 이모지·전각문자를 섞어둔 극단 케이스다.

## 탭 들여쓰기 코드 블록

일반 문단 다음, 탭으로 들여쓴 코드 블록이 온다.

	이 줄은 탭 하나로 들여써진 코드 블록의 첫 줄이다.
	두 번째 줄도 탭으로 들여써졌다.

## 연속 빈 줄

이 문단 다음에는 빈 줄이 네 개 연속으로 온다.




빈 줄 네 개를 지나 여기 새 문단이 시작된다.

## 유니코드 이모지와 전각문자

이모지가 섞인 문장이다 🎉🚀✅. 전각 문자도 있다: ＡＢＣ１２３ 　全角スペース。 그리고 화살표 기호 → ← ↔ 도 있고, 수학 기호 ≈ ≤ ≥ 도 섞여 있다.

- 이모지가 붙은 리스트 항목 ✨
- 전각 콜론이 붙은 항목：설명
- 결합 문자 테스트: 한̇글̈ (발음 구별 기호가 붙은 한글, 있을 수 있음)
