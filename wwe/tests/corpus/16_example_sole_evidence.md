# 재시도 로직 설계

네트워크 요청이 실패하면 재시도하는 것이 안정성을 높인다.

예를 들어, 우리 팀이 결제 API 호출에 지수 백오프 재시도를 적용한 뒤 타임아웃으로 인한 실패율이 4.8%에서 0.3%로 떨어졌다. 이 수치는 다른 어디에도 기록되어 있지 않다.

이 결과는 재시도 전략이 실제로 효과가 있다는 유일한 근거다.
