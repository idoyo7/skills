# 닫히지 않은 코드펜스

이 문서는 일부러 코드펜스를 닫지 않은 채로 파일을 끝낸다. mask 단계에서 이런 경우를 어떻게 처리할지가 테스트 포인트다 — 파일 끝까지를 펜스 블록으로 간주하거나, 명확한 에러/경고로 처리하거나 둘 중 하나여야 하며 어느 쪽이든 크래시하면 안 된다.

## 정상적으로 닫힌 펜스 하나

```python
print("이건 정상적으로 닫혔다")
```

## 여기서부터 닫히지 않는 펜스

```bash
echo "이 펜스는 파일 끝까지 이어진다"
curl https://example.com/never-closes

여기에 --- 같은 구분선도 있고
## 가짜 헤딩도 있고
| 표 | 처럼 | 생긴 | 것도 있다 |
|---|---|---|---|

이 모든 것이 닫히지 않은 펜스 안에 있으므로 파일 끝까지 코드로 취급되어야 한다.
