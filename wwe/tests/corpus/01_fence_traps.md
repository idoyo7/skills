# 코드펜스 함정 모음

이 문서는 코드펜스 **안**에 마크다운을 파괴할 수 있는 요소들을 잔뜩 넣어둔 테스트 케이스다. mask 단계에서 펜스 전체가 통째로 토큰화되어야 하고, 펜스 내부의 어떤 문자열도 산문에 노출되면 안 된다.

## 표가 들어있는 펜스

아래 펜스 안에는 진짜 마크다운 표처럼 생긴 텍스트가 들어있다. 이건 표로 파싱되면 안 된다.

```text
| 이름 | 값 |
|---|---|
| a | 1 |
| b | 2 |
```

## URL과 백틱이 들어있는 펜스

```bash
curl -sSL https://example.com/install.sh | bash
echo "인라인 `date` 값도 여기 있다"
export API_URL="https://api.internal.example.com/v1/users?limit=10"
```

## --- 구분선처럼 보이는 줄이 들어있는 펜스

```yaml
---

---

```

## 가짜 헤딩이 들어있는 펜스

```markdown
# 이것은 헤딩이 아니다
## 이것도 헤딩이 아니다
### 그냥 펜스 안의 텍스트일 뿐

일반 문단처럼 보이는 줄도 있다.

- 리스트처럼 보이는 줄
- 하나 더
```

## 닫는 백틱 개수가 다른 중첩 펜스 (물결표 사용)

~~~markdown
안쪽에 ``` 세 개짜리 백틱 펜스가 텍스트로 들어있어도
물결표 펜스는 안 깨져야 한다.
```python
print("이 코드는 실행되지 않는다, 그냥 예시 텍스트다")
```
~~~
