# attempts — 채택하지 않은 접근들

여기 있는 파일은 **참고용 기록이고 어디서도 참조되지 않는다.** 스킬 본문(`../SKILL.md`)도, 프로파일(`../references/docs-profile.md`)도 이 디렉토리를 읽지 않는다. 확장자를 `.orig` 로 둔 것은 Claude Code 의 스킬 탐색에 걸리지 않게 하려는 것이다.

남겨두는 이유는 하나다 — 여기서 막힌 지점을 모르면 같은 걸 다시 시도한다.

> **이름에 주의.** 이 스킬은 로컬에서 `wwe` 라는 이름으로 호출된다(`~/.claude/skills/wwe` → 이 레포). 아래 기록의 "예전 wwe" 는 **같은 이름을 쓰던 완전히 다른 구현**이다. 이름만 물려받았고 정책은 정반대다 — 예전 것은 절 순서·항목 수를 자유롭게 바꿨고, 현재 것은 그것을 불변으로 둔다.

## 예전 wwe — 구조 재건축 2단 파이프라인 (2026-08, 폐기)

`wwe-SKILL.md.orig`

문서를 **문장 단위로 다시 쓰는** 접근이었다. 원문에서 주장만 원자 단위로 뽑아 원장을 만들고(W1), 절 순서를 독자가 묻는 순서로 다시 잡고(W2), 원문을 편집하는 대신 원장을 보고 새로 쓰고(W3), 마지막에 다른 에이전트가 누락·주입·확신도 드리프트를 대조한다(W4). 그 뒤에 문체 윤문을 2단으로 붙였다.

### 실측

Hugo 기술문서 64편(전체 82만 자)에 돌렸다.

| | |
|---|---|
| 문자 변경률 | **0.1 ~ 0.6%** |
| 등급 | A/B |
| 주장 보존 | 89/89 · 162/162 · 227/227 · 246/247 … |
| 비용 | 약 14M 토큰 / 에이전트 257개 |

### 왜 채택하지 않았나

**문장을 다시 써도 원문으로 수렴했다.** 이미 한 번 윤문을 거친 문서에서 재작성의 실질 산출은 0.1~0.6%였다. 충실하게 다시 쓰면 원문 근처에 떨어지는 게 정상이고, 그렇다면 재작성 자체에 값이 거의 없다.

**그런데 크게 벌어진 지점이 사고였다.** 64편 중 유일하게 의미가 바뀐 곳이 이랬다.

```
원문   OTel Collector는 표준·벤더중립 대신 에코시스템 확장성이 강점이지만…
1단    OTel Collector의 강점은 표준·벤더중립에 더해 에코시스템 확장성이며…
```

원문은 바로 위 표의 "강점: 표준·벤더중립"을 **정정하는** 문장인데, `대신`을 `에 더해`로 바꿔 대조를 병렬로 뒤집었다. W4 가 잡아냈지만, 이 종류는 게이트로 막을 수 없다 — 문자 변경률·코드 무결성·다중집합 대조 전부 통과한다.

정리하면 **이득은 작고 위험은 실재했다.** 명명된 결함이 없는 문장을 건드려서 생긴 일이다.

### 그래서 지금 스킬은 이 축을 어떻게 다루나

문장은 `humanize-korean` 이 명명된 패턴(번역투·피동 남용·명사화 누적 등)에만 손대고, 구조는 코드가 지킨다.

블록 층 결함은 **측정하고 고치지 않는다.** `llm_signature.py` 가 L3(섹션 골격 균질성)·L4(삼분 편향)·L12(불릿 길이 균일성)·L14(헤딩 형태 병렬)를 `report` 종류로 분류하는 게 그 선택이다. 예를 들어 `tests/sig_corpus/ai_02_subtle.md` 는 이렇게 나온다.

```
발동된 actionable 지표: L1
발동된 report(고지 전용) 지표: L3, L4, L12, L14
L4  삼분 편향   1.00   리스트 블록 4개 중 3항목 블록 4개
L14 헤딩 형태 병렬 1.00  H2 헤딩 4개 중 최빈 종결형 비중 100%
```

삼분 편향 100%, 헤딩 병렬 100%를 숫자로 뽑아놓고 안 고친다. **못 보는 게 아니라 보고 안 고치는 것이다** — 고치려면 항목 수와 헤딩을 바꿔야 하고, 그건 "장식만 제거, 구조는 보존" 정책 밖이다.

### 다시 꺼내야 할 때

문서의 병이 문장이 아니라 배치일 때다. 절 순서가 틀렸거나, 문서 전체 결론이 중간 절 끝에 박혀 있거나, 표 하나가 다른 표의 부분집합이거나. 그런 건 지금 스킬이 구조적으로 손댈 수 없다.

그때 이 파일에서 가져갈 만한 것은 **W4 대조 패스**다. 집필한 컨텍스트에서 자기 글을 승인하지 않고, 누락·주입·확신도 드리프트 셋만 별도 에이전트가 판정하게 하는 구조. 위의 `대신 → 에 더해`를 잡은 게 그 패스였다.
