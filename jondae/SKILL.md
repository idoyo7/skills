# /jondae — 어투를 존댓말로 맞추는 마무리 패스

문장을 다시 쓰지 않는다. **문장 종결어미만** 존댓말로 바꾼다. 그 외에는 한 바이트도 건드리지 않는다.

```
scan(파손·평서체 계수) ─▶ fix-broken(결정적 복구) ─▶ haiku 배치 변환 ─▶ verify(전후 대조) ─▶ 승인 ─▶ 적용
    LLM 콜 없음              LLM 콜 없음              파일당 1콜        LLM 콜 없음
```

경로 변수:

```bash
JD=~/.claude/skills/jondae/scripts
```

## 1. 스캔 — 무엇이 얼마나 남았나

```bash
node $JD/scan.mjs <대상>
```

파일별 `파손` / `평서체` 건수가 나온다. **`--스캔만` 요청이면 여기서 결과를 보고하고 끝낸다.**

파손이 0이 아니면 먼저 복구한다 — LLM 을 부르기 전에 해야 한다. 이미 깨진 문장을 입력으로 주면 LLM 이 그걸 정상으로 오인한다.

```bash
node $JD/fix-broken.mjs <대상>     # --dry 로 먼저 확인 가능
```

## 2. 변환 — haiku 배치

평서체가 남은 파일만 대상이다. 파일 수가 많으면 10파일 안팎으로 나눠 **`model=haiku` 서브에이전트에 병렬 디스패치**한다. 각 에이전트에 아래 계약을 그대로 준다 (과거 study-hugo 전수교정에서 검증된 문구다).

> 당신은 한국어 기술 문서의 어투를 마무리하는 편집자입니다.
>
> **목표** — 지정된 파일들에서 평서체로 남은 **문장 종결만** 존댓말로 바꿉니다. 같은 불릿 안에서 앞문장은 존댓말인데 뒷문장만 평서체인 경우가 특히 많습니다.
>
> **절대 금지 (하나라도 어기면 실패)**
> - 단어·용어·수치·고유명사·순서 변경 금지. **문장 종결어미만** 손댑니다.
> - 코드블록(```), 인라인 코드, URL, shortcode(`{{< >}}`), 링크 문법, frontmatter, 표 행(`|`), 헤딩(`#`) — 바이트 단위로 그대로 둡니다.
> - `Σ` `✓` `≈` 같은 기호, **볼드** 마커, 이모지의 위치를 옮기거나 지우지 않습니다.
> - 영어 원문 인용은 번역하거나 바꾸지 않습니다.
> - **따옴표 안의 한국어 인용문**도 원문이므로 어투를 바꾸지 않습니다. 예: 그는 "이건 버그다"라고 썼다 → 종결 "썼다"만 "썼습니다"로.
> - 줄을 합치거나 나누지 않습니다. **줄 수를 유지합니다.**
>
> **변환 규칙**
> - `~다.` → `~습니다./~입니다.` (성립한다 → 성립합니다 / 구조다 → 구조입니다)
> - `~하다` 는 `~합니다` 입니다. **`~하입니다` 는 존재하지 않는 말입니다.**
> - 명사형·체언 종결(`— 세 가지`, `: 실패`)은 그대로 둡니다. 종결어미가 아닙니다.
> - 헤딩·표 안 문장은 대상이 아닙니다.

## 3. 검증 — 계약을 기계로 강제

변환 전 원본을 반드시 남겨두고(`git stash` 대신 사본 권장), 파일마다:

```bash
node $JD/verify.mjs <원본사본> <변환본>
```

줄 수, 보호 줄(코드·표·헤딩·frontmatter) 바이트 동일, 인라인 코드·URL·shortcode·숫자 집합 동일, 볼드 마커 수, 파손 유입 — 하나라도 어긋나면 `FAIL` 과 위반 목록이 나온다. **FAIL 파일은 채택하지 않고 원본으로 되돌린 뒤 그 파일만 재변환한다.**

전부 통과하면 diff 를 사용자에게 보이고 승인받아 적용한다.

## 왜 이렇게 나눴나

LLM 에게 "구조를 지켜라"라고 부탁하는 것으로는 안 지켜진다. 과거 study-hugo 전수교정에서 실제로 42건이 깨졌고, `필요하입니다` 같은 문법 파손이 90건/58파일 나왔다. 그래서 **지킬 수 있는 것은 코드가 지키고**(마스킹·검출·복구·대조), LLM 에게는 코드로 판정할 수 없는 것 하나만 맡긴다 — 이 `~다`가 정말 문장 종결인가.

## 파손 규칙의 보수성

`fix-broken` 은 잡을 수 있는 파손을 다 잡지 않는다. `명사 + 입니다`와 충돌하는 패턴은 실데이터 코퍼스 대조로 걷어냈다 — `적입니다`(구체적·효과적), `크입니다`(리스크·벤치마크), `작입니다`(동작·재시작)는 규칙에 없고, `하입니다`는 `이하·부하·은하` 같은 명사를 예외로 뺀 뒤에만 적용한다. 오탐 한 건이 곧 문서 훼손이라, 놓치는 쪽을 택했다. 남는 파손은 §3 verify 의 파손 유입 검사와 사람 diff 검토가 잡는다.

## 주의

- **자기 자신을 포함한 에이전트 지시 파일(CLAUDE.md·AGENTS.md·SKILL.md)은 대상이 아니다.** 어투를 바꾸면 에이전트 행동이 바뀐다.
- 코드 주석·API 문서처럼 형식이 정해진 텍스트도 대상이 아니다.
- 이 스킬은 문체를 다듬지 않는다. AI 티 제거는 [wwe](../wwe/SKILL.md).
