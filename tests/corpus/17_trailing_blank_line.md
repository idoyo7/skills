# 끝에 빈 줄이 남는 배포 노트

이 문서는 마지막 줄이 빈 줄로 끝나는 상황을 재현하기 위한 픽스처다. 자세한 절차는 [배포 가이드](https://example.com/docs/deploy)를 참고하라.

## 배포 전 점검

아래 명령으로 현재 브랜치 상태를 확인한 뒤 배포를 시작한다.

```bash
git status --short
echo "이 코드는 끝개행 버그와 무관하게 그대로 보존돼야 한다"
```

점검이 끝나면 아래 표에 결과를 기록한다.

| 항목 | 결과 |
| --- | --- |
| 브랜치 확인 | 완료 |
| 테스트 통과 | 완료 |

본문은 여기서 끝나지만, 파일은 빈 줄 하나를 더 남기고 종료한다.
