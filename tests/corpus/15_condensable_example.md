# 재시도 로직 설계

네트워크 요청이 실패하면 재시도하는 것이 안정성을 높인다. 재시도는 시스템의 신뢰성을 개선하는 핵심 기법이다.

예를 들어, 어떤 팀은 결제 API 호출에 지수 백오프 재시도를 적용해서 일시적인 타임아웃으로 인한 실패율을 낮췄다고 한다. 이런 사례들은 흔히 들을 수 있는 이야기이며, 재시도가 일반적으로 안정성에 도움이 된다는 점을 다시 한번 보여준다.

결국, 재시도 로직을 도입하면 시스템이 더 안정적으로 동작한다. 이것이 이 섹션의 핵심 요지다.

## 정리

지금까지 설명했듯이, 재시도는 안정성을 높이는 좋은 방법이다. 위에서 다룬 내용을 요약하면, 일시적 오류에 재시도를 적용하는 것이 바람직하다.
